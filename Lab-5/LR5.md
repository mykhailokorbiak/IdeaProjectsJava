## Теоретичні відомості

**Метод** — це частина програми, яка виконує певну дію.  
Методи дозволяють розділити програму на окремі логічні блоки, щоб код був простішим, зрозумілішим і зручнішим для повторного використання.

Метод може:
- приймати параметри;
- виконувати певні дії;
- повертати результат;
- нічого не повертати, якщо використовується тип `void`.

Наприклад:

```java
public static int sum(int a, int b) {
    return a + b;
}
```

У цьому прикладі метод приймає два числа та повертає їх суму.

## Код програми

```java
import java.util.Scanner;

public class Main {

    // Метод для обчислення площі ромба
    public static double areaRhombus(double d1, double d2) {
        return (d1 * d2) / 2;
    }

    // Метод, що приймає три числа, виводить і повертає найменше
    public static int minOfThree(int a, int b, int c) {
        int min = a;

        if (b < min) {
            min = b;
        }

        if (c < min) {
            min = c;
        }

        System.out.println("Найменше число: " + min);
        return min;
    }

    // Метод, що виводить масив
    public static void printArray(int[] array) {
        System.out.print("Масив: ");
        for (int i = 0; i < array.length; i++) {
            System.out.print(array[i] + " ");
        }
        System.out.println();
    }

    // Метод, що повертає найбільше число з масиву
    public static int maxInArray(int[] array) {
        int max = array[0];

        for (int i = 1; i < array.length; i++) {
            if (array[i] > max) {
                max = array[i];
            }
        }

        return max;
    }

    // Безпечне введення цілого числа
    public static int inputInt(Scanner scanner, String message) {
        while (true) {
            System.out.print(message);

            if (scanner.hasNextInt()) {
                return scanner.nextInt();
            } else {
                System.out.println("Помилка! Введіть ціле число.");
                scanner.next();
            }
        }
    }

    // Безпечне введення дробового числа
    public static double inputDouble(Scanner scanner, String message) {
        while (true) {
            System.out.print(message);

            if (scanner.hasNextDouble()) {
                return scanner.nextDouble();
            } else {
                System.out.println("Помилка! Введіть число.");
                scanner.next();
            }
        }
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        double d1 = inputDouble(scanner, "Введіть першу діагональ ромба: ");
        double d2 = inputDouble(scanner, "Введіть другу діагональ ромба: ");

        double area = areaRhombus(d1, d2);
        System.out.println("Площа ромба = " + area);

        System.out.println();

        int a = inputInt(scanner, "Введіть перше число: ");
        int b = inputInt(scanner, "Введіть друге число: ");
        int c = inputInt(scanner, "Введіть третє число: ");

        minOfThree(a, b, c);

        System.out.println();

        int n = inputInt(scanner, "Введіть кількість елементів масиву: ");

        while (n <= 0) {
            System.out.println("Кількість елементів має бути більшою за 0.");
            n = inputInt(scanner, "Введіть кількість елементів масиву: ");
        }

        int[] arr = new int[n];

        for (int i = 0; i < n; i++) {
            arr[i] = inputInt(scanner, "arr[" + i + "] = ");
        }

        printArray(arr);

        int max = maxInArray(arr);
        System.out.println("Найбільше число в масиві: " + max);

        scanner.close();
    }
}
```

## Опис роботи програми

У програмі створено чотири основні методи.

### 1. Метод `areaRhombus`

```java
public static double areaRhombus(double d1, double d2)
```

Метод приймає дві діагоналі ромба та обчислює його площу за формулою:

```text
S = (d1 * d2) / 2
```

Після обчислення метод повертає результат.

---

### 2. Метод `minOfThree`

```java
public static int minOfThree(int a, int b, int c)
```

Метод приймає три цілі числа, порівнює їх між собою, виводить найменше число на екран та повертає його.

---

### 3. Метод `printArray`

```java
public static void printArray(int[] array)
```

Метод приймає масив цілих чисел і виводить усі його елементи на екран.

---

### 4. Метод `maxInArray`

```java
public static int maxInArray(int[] array)
```

Метод проходить по всіх елементах масиву, знаходить найбільше число та повертає його.

---

### 5. Методи перевірки введення

У програмі додано методи:

```java
inputInt()
inputDouble()
```

Вони перевіряють, чи користувач ввів саме число.  
Якщо користувач вводить букви або інші неправильні символи, програма не завершується з помилкою, а просить повторити введення.
