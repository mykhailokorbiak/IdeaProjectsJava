# Лабораторна робота №4: Масиви в Java

## 📝 Опис

Мета роботи — навчитися працювати з масивами в мові Java: створення, заповнення, перебір та обробка елементів.

---

## 🛠 Вимоги

- Java Development Kit (JDK) 17+
- IntelliJ IDEA / VS Code / Eclipse

---

## 📋 Завдання

### 🔹 Завдання 1

Створити два масиви:
- 50 парних чисел
- 50 непарних чисел

```java
int[] even = new int[50];
int[] odd = new int[50];

for (int i = 0; i < 50; i++) {
    even[i] = i * 2;
    odd[i] = i * 2 + 1;
}
```

---

### 🔹 Завдання 2

Дано масив:

```java
int[] arr = {2, 17, 13, 6, 22, 31, 45, 66, 100, -18};
```

Виконати:
- перебір через while
- перебір через for
- вивести елементи з непарними індексами
- вивести елементи з парними індексами
- вивести масив у зворотному порядку

---

### 🔹 Завдання 3

Обчислити суму елементів масиву.

```java
double sum = 0;

for (int i = 0; i < numbers.length; i++) {
    sum += numbers[i];
}
```

---

### 🔹 Завдання 4

Змінити знак всіх непарних елементів масиву.

```java
for (int i = 0; i < arr.length; i++) {
    if (arr[i] % 2 != 0) {
        arr[i] = -arr[i];
    }
}
```
