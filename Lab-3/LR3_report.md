# Лабораторна робота №3: Цикли в Java

## Опис

Метою лабораторної роботи є ознайомлення з циклами `for` та `while` у мові Java.  
У роботі реалізовано програму, яка демонструє повторення дій за допомогою циклів.

---

## Вимоги

- Java Development Kit (JDK) 17+
- IntelliJ IDEA / VS Code / Eclipse

---

## Завдання

### 1. Вивести рядок 50 разів
Реалізовано через:
- цикл `for`
- цикл `while`

---

### 2. Години та хвилини (for)

Вивести час у форматі:
```
h год m хв
```

---

### 3. Години та хвилини (while)

Аналогічно до попереднього, але через цикл `while`.

---

### 4. Години, хвилини, секунди

Реалізовано вкладені цикли:
- години
- хвилини
- секунди

---

### 5. Табулювання функції

Обчислення функції:
```
f(x) = x²
```

- інтервал: [0; 2]
- крок: 0.1

---

## Запуск програми

### Компіляція
```
javac *.java
```

### Виконання
```
java Main
```

---

## Висновок

У ході лабораторної роботи було освоєно використання циклів `for` та `while`.  
Було реалізовано задачі з повторенням дій та вкладеними циклами.  
Отримано практичні навички побудови циклічних алгоритмів.
