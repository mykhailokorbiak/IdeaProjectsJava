# Лабораторна робота №1: Перша програма на Java

## 📝 Опис

Метою лабораторної роботи є ознайомлення з основними можливостями мови
програмування **Java**.\
У ході роботи було реалізовано програму, яка демонструє використання:

-   базових типів даних
-   арифметичних операцій
-   роботи з рядками
-   масивів об'єктів
-   класів та методів
-   принципів об'єктно-орієнтованого програмування

------------------------------------------------------------------------

## 🛠 Вимоги

Для запуску програми необхідно:

-   **Java Development Kit (JDK)** версії **17+**
-   будь-яке середовище розробки (IntelliJ IDEA, VS Code, Eclipse)
-   Git (за потреби для роботи з репозиторієм)

------------------------------------------------------------------------

## 📋 Завдання

### 1. Арифметичні операції

У програмі реалізовано виконання арифметичних операцій над набором
чисел:

-   додавання
-   віднімання
-   множення
-   ділення

Використані типи даних:

-   `int`
-   `long`
-   `double`

------------------------------------------------------------------------

### 2. Робота з рядками

Створено декілька змінних типу `String`, які об'єднуються в одне речення
за допомогою оператора конкатенації `+`.

Приклад результату:

    Я вчуся писати програми мовою Java та виконую лабораторну роботу.

------------------------------------------------------------------------

### 3. Робота з об'єктами

Створено клас **User**, який містить поля:

-   id
-   age
-   firstName
-   lastName
-   weight
-   height

Далі створено масив з **10 об'єктів User**.

За допомогою циклу `for-each` обчислено:

-   суму віку
-   суму ваги
-   суму зросту

------------------------------------------------------------------------

### 4. Робота з класом Car

Створено клас **Car**, який описує автомобіль.

Поля класу:

-   power
-   engineVolume
-   brand
-   model
-   year
-   color
-   fuelType

Створено масив із **10 автомобілів**.

Обчислено:

-   сумарну потужність
-   сумарний об'єм двигуна

------------------------------------------------------------------------

### 5. Математичний алгоритм

Реалізовано алгоритм **реверсу тризначного числа**.

Використано оператори:

-   `/` --- ділення
-   `%` --- залишок від ділення

Алгоритм:

1.  отримати останню цифру числа
2.  отримати середню цифру
3.  отримати першу цифру
4.  сформувати число у зворотному порядку

------------------------------------------------------------------------

## 🚀 Запуск програми

### Компіляція

``` bash
javac Main.java
```

### Виконання

``` bash
java Main
```

Після запуску програма виконує всі завдання та виводить результати в
консоль.

------------------------------------------------------------------------
